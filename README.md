# Commutas — Mobile Application

A Flutter-based campus transport wallet for COMSATS University Islamabad, Abbottabad Campus. Features NFC Host Card Emulation for phone-to-phone fare collection, digital wallet management, trip sessions, live bus tracking, and portal-verified student identity.

> **Android only.** The core fare validation mechanism depends on NFC Host Card Emulation, which is not available to third-party applications on iOS.
